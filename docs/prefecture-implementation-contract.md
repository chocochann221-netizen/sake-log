# 都道府県ページ実装基準 Ver.1

## 基準画面

奈良県ページを47都道府県の共通UI基準とする。

1. 土地を一目で感じるヒーロー写真
2. 県名と最小限の導入文
3. 地域・文化を伝える写真
4. 食を伝える写真
5. 木札型の代表酒蔵2件
6. 全酒蔵一覧への導線
7. ホーム・MY LOG・知識の蔵の固定ナビゲーション

写真、文章量、スクロールの緩急は県ごとに変えるが、操作位置と酒蔵への到達方法は共通化する。

## 酒蔵データ境界

県ページと酒蔵一覧は、必ず `prefecture-brewery-source.js` を通して酒蔵情報を読む。

- 現在のモードは `audited-static-snapshot`。
- 変更中のDBテーブルへ県ページから直接接続しない。
- DB移行中に静的データとDBへ二重書き込みしない。
- 酒蔵詳細ページは、DBの読取モデルと識別子が確定するまで作成しない。
- DB接続後はデータソース実装だけを交換し、県ページと一覧ページのUIは変更しない。
- DB取得失敗時の静的フォールバックを採用する場合も、同一セッション内でデータを混在させない。

## 酒蔵詳細で必要になる安定項目

DB確定時に次の項目を一つの読取モデルへ揃える。

- 永続的な酒蔵ID
- 表示名・法人名
- 都道府県・市区町村・住所
- 代表銘柄
- 公式サイトURL
- 営業・製造状態
- 情報源URL
- 最終確認日

画面側は列名へ直接依存させず、データソース層で `name / brands / place / note / url` の表示形式へ変換する。

## 展開Gate

奈良県で以下を通過してから他県へ展開する。

- 県ページを開ける
- 代表酒蔵2件を表示できる
- 全酒蔵一覧へ進める
- 検索結果件数が正しい
- 一覧から県ページへ戻れる
- 写真クレジットと外部リンクが機能する
- JavaScriptエラーがない
- 酒蔵DBへの書込みが発生しない
