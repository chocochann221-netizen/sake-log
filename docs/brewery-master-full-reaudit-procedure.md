# 全国酒蔵マスター 全面再監査手順

更新日: 2026-09-21

## 目的
brewery_master を候補マスターとして一件ずつ再検証し、酒蔵の現存、製造主体、所在地、代表銘柄、公式Web、公式EC、重複を確定する。

## 基本原則
- 旧DBのURLや旧監査結果だけで確定しない。
- 公式サイトが見つからないことと、公式Webページが存在しないことを同義にしない。
- URLは推測で登録しない。
- 公式ECは実際に商品を購入できる取引ページを確認した場合だけ official_shop_exists=true とする。公式ホームページをECとして代用しない。
- 酒造組合への加盟・非加盟は収録条件にしない。

## 監査順序
1. 酒蔵名・法人名・代表銘柄で通常検索する。
2. 既存URLがある場合も現行ページ、法人名、所在地、銘柄を再確認する。
3. 公式サイトが通常検索で見つからない場合、次の「公式サイトなし判定前の必須確認」をすべて実施する。
4. 酒造組合、日本酒造組合中央会、自治体・観光協会等の公的/業界情報で現存・所在地・銘柄を突合する。
5. 公式ECは公式サイトとは別に確認する。
6. 同名法人・同名酒蔵・県跨ぎ・旧称・移転・休廃業・事業承継を確認する。
7. 根拠URLと確認内容を full_reaudit_evidence / full_reaudit_notes に残す。
8. DB更新後に対象行を読み戻し、最後に集計件数を再取得する。

## 公式サイトなし判定前の必須確認
「公式サイトなし（official_site_url = null）」と確定する前に、以下を**必ず全項目確認する**。

1. **古いドメイン・旧式Web**
   - HTTPのみ、www有無、旧プロバイダ領域、古いHTMLサイト、ブランド名ドメイン、旧社名ドメインを検索する。
   - 検索結果だけでなく、現行の酒造組合・自治体等がそのURLを蔵元Webとしてリンクしているか確認する。

2. **酒造組合・業界団体の蔵元リンク**
   - 都道府県酒造組合、日本酒造組合中央会、地域酒造組合、信頼できる業界団体の酒蔵紹介ページを開く。
   - 「公式サイト」「ホームページ」「Web Site」等の外部リンクがあれば遷移先まで確認する。

3. **自治体・公的観光サイトからの外部リンク**
   - 市区町村、都道府県、公式観光協会、地域産品の公的ページを確認する。
   - 酒蔵紹介から外部サイトへのリンクがあれば遷移先まで確認する。

4. **共有URL・短縮URL・Google共有URLの遷移先**
   - ユーザー提供の share.google 等の共有URLは、URL文字列だけで判定せず、可能な限り遷移先を確認する。
   - 遷移先の酒蔵名、法人名、所在地、銘柄を他の公式/公的情報と突合する。

5. **ブランド名・住所・電話番号からの逆引き**
   - 法人名だけで見つからない場合は代表銘柄、住所、電話番号、旧称を組み合わせて再検索する。

上記を完了しても蔵元Webを確定できない場合に限り official_site_url を null とする。その際は full_reaudit_notes に「必須確認済み・公式Web確定できず」と明記し、確認した主要ソースを full_reaudit_evidence に保存する。

## 判定
- verified: 酒蔵の現存・主体・所在地等を十分な根拠で確認。
- needs_review: 主体、所在地、現存、重複等に重要な不確実性が残る。
- duplicate_candidate: 同一実体の重複可能性が高い。
- inactive_candidate: 休廃業等の可能性があり追加確認が必要。
- pending: 未監査。

## 監査単位
原則20件単位。各バッチで「取得 → 外部確認 → DB更新 → 全件読み戻し → 集計再取得」までを1セットとする。
