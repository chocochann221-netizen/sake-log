# 和酒ログ「知識の蔵」写真権利台帳

最終更新: 2026-09-09

## 運用ルール

- 許諾不要で利用条件が明示された写真だけを採用候補にする。
- 優先順位は CC0 → CC BY → 条件を管理できる CC BY-SA。
- 公式サイト等の写真は、転載・二次利用条件が明示されない限り参考資料のみ。
- 採用時は、作品名 / 権利者 / ライセンス / 出典URL / 必要なクレジットを必ずセットで管理する。
- 画像ファイルをアプリへ取り込む前に、個別資料ページで利用条件を再確認する。
- CC BY素材はアプリ内で出典・権利者・ライセンスを利用者が確認できる形で表示する。
- 国・自治体サイトは「公的サイトだから自由に使える」と判断しない。写真は第三者権利が含まれる場合があるため、個別利用条件が明示されない限り「要確認」とする。

### 米比較ページで狙う写真

1. 酒造好適米と主食用米を同じ倍率で並べた玄米写真
2. 心白が見える玄米または断面写真
3. 精米前 → 精米後を同じ品種で並べた写真
4. 山田錦など大粒品種とコシヒカリ等を同一スケールで比較した写真

写真が揃わない場合は、無理に公的サイトの写真を転載せず、蔵元・農家・研究機関への許諾依頼、または和酒ログ独自撮影を優先する。

## 利用ルール確認メモ

- 農林水産省のコンテンツ本文はPublic Data License等に基づく利用が可能な場合がある。
- ただし同省の利用ルールでは、写真等の画像は第三者が権利を持つ場合が多いため、利用希望時は担当課に確認するよう明記されている。
- したがって農水省掲載写真は「サイトが公的＝そのまま商用利用可」とは扱わない。

## 次に確認するもの

- 蒸米の実作業写真
- 醪が発酵している状態が分かる写真
- 生酛の山卸・酛摺り
- 袋吊りで雫が落ちる瞬間
- 現代の火入れ（熱交換器・瓶燗）
- 現代の自動圧搾機
- 山田錦と主食用米の同条件比較写真
- 心白が明確に見える、利用条件確定済み写真
- 精米前後の比較写真

上記も同じ基準で、個別ページの権利条件まで確認できたものだけを追加する。
