# 都道府県ページ 現行正本

このディレクトリは、都道府県ページで採用された現行デザインと、実装表示の検証画像を保全するための正本です。

- `approved/`: ユーザー承認済みの都道府県トップ画。旧案や比較案は置かない。
- `verification/`: 現行実装を追加CSSなしで描画した酒蔵一覧の全画面画像と先頭確認画像。
- 酒蔵名・所在地・代表銘柄の実データは `prefecture-brewery-data.js` を正本とする。
- 酒蔵一覧の画面実装は `brewery-list.html` を正本とする。
